# SACA Smart Assistant — Version 5

## المزايا
- رحلة متتالية: لغة ثم قسم رئيسي ثم قسم فرعي ثم وجهة.
- لا تظهر كل القوائم في الشاشة نفسها.
- أزرار رجوع وبدء من جديد.
- بيانات حقيقية للدور الأرضي والأول.
- ترجمة المنطقة في الواجهة الإنجليزية.
- زر استماع مطور مع اختيار صوت عربي أو إنجليزي وحالة تشغيل.

## التشغيل
```bash
pip install -r requirements.txt
streamlit run app.py
```

ملاحظة: تشغيل الصوت يعتمد على أصوات النظام والمتصفح. يفضل Chrome أو Edge.
